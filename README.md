# -AI-

## 已知限制
- 当前体验以桌面浏览器为主，对移动端仅做基础适配，窄屏可能需要横屏或放大才能完整展示流程。
- 建议分辨率至少 1440px 宽，低于该分辨率可能出现布局拥挤或元素重叠。
- 某些操作需要网络连接，离线时功能将受限。

## 兼容性 / 测试矩阵
| 平台 | 浏览器 | 状态 | 备注 |
| --- | --- | --- | --- |
| 桌面 | Chrome / Edge / Firefox | ✅ 主要使用场景，布局和交互已验证 | 推荐分辨率 ≥1440px 宽 |
| 桌面 | Safari | ⚠️ 可用但未覆盖所有边界场景 | 可能存在样式差异 |
| 移动 | 移动端 Chrome / Safari | ⚠️ 基础可用，未针对小屏优化 | 建议横屏使用，复杂操作优先在桌面完成 |

## 最小可行手动测试流程
1. 通过应用入口创建新项目，确认项目名称与保存位置可用。
2. 依次执行六个核心阶段（如素材导入、整理、生成、审校、调整、导出），每步完成后检查状态同步。
3. 在导出阶段选择默认配置生成结果文件，确认下载/保存无报错。
4. 若任一阶段产出为空，可尝试改用更具体的关键词（示例：在提示词中加入领域、风格或用途限定）。

## 未来改进方向
- 增强离线模式：在网络不稳定时提供有限的本地缓存与重试策略。
- 本地模型适配：提供可选的本地推理后端以减少延迟和数据外发。
- 更完善的移动端体验：针对小屏设备的分步视图与触控优化。
